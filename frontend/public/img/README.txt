Place your images in this folder.
They will be served at: /img/your-image.jpg

Leader profile image should be named: leader.jpg (or leader.png)
Example usage in code: <img src="/img/leader.jpg" />

Home page auto-slide banner:
Add files named banner1.jpg, banner2.jpg, banner3.jpg, ... (up to banner12)
Any of these extensions works: .jpg .jpeg .png .webp
Numbers can skip around (e.g. only banner1.jpg and banner4.png) — the site
only shows the slots that actually have a file. No code changes needed,
just drop the files in and refresh.
